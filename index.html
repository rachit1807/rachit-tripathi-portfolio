AI Resume Analyzer

Career tools · NLP and matching

AI Resume Analyzer

A Flask career platform for resume analysis, job matching, skill gaps, candidate tools, and recruiter workflows.

PythonFlaskTF-IDFscikit-learnPostgreSQL
Explore case study ↗

Problem and approach

Applicants need an understandable view of resume coverage against a role. The analyzer extracts text from text-based PDFs, calculates an ATS-style completeness score, compares resume and job text with TF-IDF and cosine similarity, and reports skills from a defined catalogue. These are estimates and heuristics, not hiring recommendations.

Architecture

  1. Flask viewsAnonymous analysis and account tools
  2. Parser + servicesPDF text, scoring, matching, guidance
  3. SQLAlchemyCandidate, recruiter, and report records
  4. SQLite / PostgreSQLLocal fallback / durable deployment

Quality and demo

  • Automated route and service tests are included under tests/ and run with pytest. The README says tests use isolated SQLite databases and do not send email or call external AI services.
  • Try the anonymous analyzer with a text-based sample or redacted PDF and a target job description. Account history and recruiter workflows require durable PostgreSQL; the app's resume tools use local rules and templates rather than a hosted language model.

SmartLoanAI

The project models an application review flow with an eligibility estimate, repayment calculations, and document checks. Its code keeps document verification status separate from the loan decision, so reviewing a file does not silently approve or reject an application.

Architecture

  1. React appApplicant and admin screens
  2. FastAPIAuth, loan, document, and admin routes
  3. ML + calculationsEligibility estimate and repayment figures
  4. SQL databaseNeon PostgreSQL live; SQLite local

Quality and demo

  • This is an educational demonstration, not a lending decision service. Use sample financial details and documents only. The README notes that uploaded file contents use Render's local filesystem and may not survive a restart or redeploy.

RailYatra

Full-stack · Railway booking simulator

RailYatra

A railway journey simulator with route search, automatic seat allocation, simulated checkout, PNR lookup, and downloadable demo tickets.

JavaScriptNode.jsExpressPostgreSQL
Explore case study ↗

Problem and approach

A booking flow needs to keep availability, checkout holds, and reservations consistent. RailYatra combines account sessions, route search, automatic seat allocation, temporary holds, simulated payments, cancellation, and demo ticket downloads. PostgreSQL transactions and inventory locks coordinate overlapping route segments; checkout idempotency handles retries.

Architecture

  1. Browser interfaceHTML, CSS, and JavaScript modules
  2. Express APISessions, search, bookings, and checkout
  3. PostgreSQLAccounts, seat inventory, holds, and ledger
  4. Render + NeonSame-origin app and hosted database

Quality and demo

  • The repository includes JavaScript syntax checks, unit tests, and PostgreSQL integration tests. GitHub Actions runs these checks for pull requests and before publishing the static frontend.
  • Use the full-stack demo and choose Explore with a demo account to try the complete booking flow. The GitHub Pages preview uses a separate API origin; browser privacy settings may restrict sign-in cookies there.
  • This is an independent learning project with simulated availability, fares, payments, and tickets. It has no live railway or IRCTC integration; demo tickets are not valid for travel. Free hosting may need time to wake up.
